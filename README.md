# ⚽ EL CLÁSICO: Real Madrid vs Liverpool FC (Next.js + Supabase)

**El Clásico** futbol jamoalari boshqaruvi, o'yinchilar statistikasi, davomat taqvimi va jonli telemetriya tahlillari platformasi!

---

## 🌟 Asosiy Imkoniyatlar:

1. **Doimiy Qorong'u Telemetriya Dizayni (Dark Mode)**:
   - EA Sports FC va professional telemetriya uslubidagi toza qora interfeys (`#070a14`).
   - 3D FUT kartochkalar, golografik nurlar va jonli reyting ko'rsatkichlari.

2. **Haqiqiy Ma'lumotlar va Dinamik Grafik (Zero-Fake Data)**:
   - Barcha statistika 0 dan boshlanadi.
   - O'yin kiritilgandagina real ko'rsatkichlar asosida dinamik svg-grafik chiziladi.

3. **To'liq Davomat Taqvimi (Attendance Calendar)**:
   - 2026–2027 yillar uchun to'liq davomat tizimi.
   - Kelajakdagi kunlar kelmaguncha davomat belgilab bo'lmaydi.
   - Davomat natijalari o'yinchilarning reytingiga to'g'ridan-to'g'ri ta'sir qiladi.

4. **Bulutli Ma'lumotlar Bazasi (Supabase Sync)**:
   - Barcha o'yinchilar, o'yinlar va davomat ma'lumotlari Supabase PostgreSQL bazasida saqlanadi.
   - Qaysi qurilmadan (telefon, noutbuk) kirmang, real vaqtda bir xil ko'rinadi.
